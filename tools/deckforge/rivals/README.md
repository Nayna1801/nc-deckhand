# Rivales extra (no forman parte del campo por defecto)

Mazos rivales que se pasan con `--vs` a `vs.py`, `side_plan.py`, `side_plan_pkg.py`, `side_assemble.py`, `replace_card.py` o `best.py --vs`
(por ruta, p. ej. `--vs tools/deckforge/rivals/ryy_royce_muamar.json:0.35`). No están en `meta/` para no cambiar el campo por defecto
(`gauntlet`, `matrix`, `golden.py`...).

- `ryy_royce_muamar.json` / `.txt`: RYY (Royce + River Ward + Muamar Reyes), 45 cartas + 6 de sideboard. **Lista real que pasó el usuario (2026-11-13)**.
- `ryy_smasher_muamar.json`, `ryy_royce_viktor.json`, `ryy_smasher_viktor.json`: la misma lista con las variantes que dice el usuario
  (Royce por Adam Smasher; Muamar por Viktor Vektor). Solo cambian las Legends; la lista de 45 cartas es la misma.
